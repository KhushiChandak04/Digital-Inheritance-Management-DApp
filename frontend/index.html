CONTROL & TRUST

Security posture

The controls that keep this academic prototype understandable and auditable.

⌁

Role-based access

Owner, executor, beneficiary, and public caller permissions are enforced by the deployed contract.

◷

Timelocked release

Verification starts a waiting period. The owner can cancel while the review window is open.

≋

Deterministic allocation

Shares are stored on-chain and must equal exactly 100% before verification can begin.

!

Prototype boundary

This is not a legally binding will. Real-world verification remains an off-chain responsibility.
